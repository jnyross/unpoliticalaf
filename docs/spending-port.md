comparisons, quick answers, adjacent semantic tables, methods, impartial palette
and original automated reading approximation. It uses the existing seeded
Treasury and OBR workbooks and their unmodified catalogue.

The new orchestration keeps the baseline's output-location and contamination
checks, publishes an exact allowlist and removes only the known legacy CSS
file. Rendering consumes validated data in memory. It does not read feature
flags or private runtime files. Source validation and rendering precede public

failure during replacement can still leave mixed output, so the controller must
deploy only a fully checked candidate and retain the last good deployment.

The port rejects non-finite numbers and changed catalogue/source hashes.
Blank and dash-marked missing cells remain null, and a missing required operand
stops reconciliation. Missing chart points split the line; definition breaks
also split it. A second reader checks source cells and JSON, independently sums
areas and debt components and checks the inflation base year. Browser smoke checks exercise the view controls,\nexpand tables, audit both widths and check core content with JavaScript disabled.\nReproducibility
compares two freshly generated payloads with every existing public file.

has been removed. PESA outturns may be revised, the newer OBR historical vintage
has its own status caveat, and the Treasury forecast date is not applied to OBR.
Ten detail items are labelled as selected and as sitting within the area totals. This port
does not certify an exhaustive top-ten ranking or classify each OBR historical
cell. Those limits are stated beside the relevant content.
